# 主体标签拆成两个正交字段

内容打标用「主体类型」（文档级）与「内容性质」（切片级）两个独立字段，而不是单一的主体类型字段。

最初的方案是单字段若干类，问题在于**这些类不在同一个轴上**：「角色」「地点」回答"讲的是什么"，「打法」「数值」回答"讲的是哪一面"。一个讲"二郎神攻击力"的切片会同时落进两个类，分类互相打架，过滤就失去了价值。

拆开后各归其位：主体类型对应"这是谁"，文档级，一份文档一个；内容性质对应"这段回答什么问题"，切片级——「背景故事」和「打法」在同一个页面里，硬统一就废了。

**代价**：标注要跑两遍，且内容性质**不能**沿用原项目"读完前几块、回写全文档"的做法，必须逐切片判断（可用切片在文档中的位置作为弱上下文），成本更高。
