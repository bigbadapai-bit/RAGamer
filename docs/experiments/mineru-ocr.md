# 实验：MinerU 能提取多少图内文字

2026-09-13 · T10（#11）要求「上生产前必须做的实验」（见 [`../ARCHITECTURE.md`](../ARCHITECTURE.md) §1.3）。

**结论：必须依赖二次 OCR 的比例 = 100%（56 / 56 个图片条目，两个后端完全一致）。**
换言之，独立上传的攻略截图里，MinerU 一个字的图内文字都没给——二次 OCR 不是兜底，
是这类资料**唯一**的信息来源。

## 怎么跑的

```bash
# 素材：22 张真实攻略截图（长图、表格截图、wiki 截图混合）
uv run python tools/mineru_ocr_experiment.py test_screen_shots --out docs/experiments/mineru-ocr.md
```

- 素材 22 张（票里写的是 20 张，实际给了 22 张，全跑），`pipeline` 与 `vlm` 各跑一遍，
  共 44 次解析，**全部成功，无失败**。
- 判定口径：一个 `type == "image"` 的条目算「有文字」，当且仅当
  ① 条目自带 `text` / `content` 字段且非空，或
  ② 正文里这张图的引用之后紧跟一个标着 `<summary>text_image</summary>` 的折叠块。
  两者都没有即「有图无字」。
- 分母是**图片条目**，不含 `text` / `table` 条目。

## 结果

| 后端 | 图片条目 | 有图无字 | 必须依赖二次 OCR 的比例 |
| --- | --- | --- | --- |
| pipeline | 56 | 56 | **100.0%** |
| vlm | 56 | 56 | **100.0%** |

逐张明细见下面的原始表。两个后端**逐张完全一致**（每张的图片条目数与有图无字数都一样）。

### 三点读表时要留意的

1. **3 张截图的图片条目为 0**（`12-30-52`、`12-33-34`、`12-33-58`）——那几张是纯文字截图，
   MinerU 把文字抽成了 `text` / `table` 条目（正文 600–900 字，已逐张核对），
   本来就没有图片区域。它们不进分母，也不是解析失败。
2. **条目数差异很大**：多数截图整页就是**一个**图片区域（长图尤其如此），
   最多的一张切出 17 个（wiki 页里的小图/图标）。所以二次 OCR 要能对付「整页一张大图」。
3. **vlm 的 `content` 字段是空的**：`vlm` 后端的 image 条目比 `pipeline` 多一个 `content`
   字段，实测**全是空串**。

## 实测推翻的两处文档假设

- **§1.2 说的「转机」在云端没有生效。** 文档写「VLM 后端的 `image_analysis` 默认开启，
  图内文字落在正文的 `<details><summary>text_image</summary>` 折叠块里」。
  实测：产物里**没有 `<details>`**，vlm 与 pipeline 的结果逐张一致，图内文字一个字都没有。
  与 §1.2 自己列的第三点（云端不暴露 `image_analysis`，是否开启属未确证项）吻合——
  现在确证了：**云端 vlm 这些截图上是没开/没生效的**。
- **真要有图内文字，落点是 `content_list` 条目的 `content` 字段**，不是正文折叠块。
  本次实测该字段全空，所以这一条只是「字段存在」层面的观察，不代表它填过值。

## 对下一张票（T12 图片补全）的范围含义

1. **二次 OCR 是必需项，不是可选项。** 不做，这批资料的 56 个图片条目信息全丢，
   而且**不报错**——用户只会觉得「问图里的东西答不出来」。
2. **范围就是 content_list 里每一个 `type == "image"` 的条目，不设阈值、不挑大小图。**
   比例是 100%，没有「小图跳过」的余地；跳过任何一张都是静默丢信息。
3. **图片本身仍要保留。** 图内文字补进正文之外，原图要能在答案里展示（ADR-0006 的代价那一节）。
4. **T12 原定的第一件事（展开 HTML 折叠块）在本批实测里没有对象**——产物里根本没有折叠块。
   范围应按这次实测调整（或降级为「见到就展开」的防御性处理），
   但**别的输入类型（PDF、表格截图以外的形态）未测**，不能据此认定折叠块永远不出现。

## 限制

- 素材只有 22 张、且全是**图片**来源；PDF 那条路没测（票里的实验只要求截图）。
- 单次运行的时间点：2026-09-13，云端后端行为会变（`image_analysis` 若哪天对云端开放，
  这个 100% 会变）。重跑一条命令即可复核。
- 「有文字」只看**有没有**，没看**质量**；二次 OCR 出来多少能用，要在 T12 里再看。
